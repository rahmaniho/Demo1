# نورپارس — وب‌سایت فارسی شرکت پنجره

بازنویسی کاملِ قالب تک‌صفحه‌ای «Northlight Windows» برای ایران و زبان فارسی:
راست‌چین (RTL)، تایپوگرافی فارسی (وزیرمتن + مرکزی)، محتوای بومی، اعداد فارسی
و آمادهٔ انتشار روی **GitHub Pages**.

## ✨ ویژگی‌ها

- 🌙 طراحی تیره و ادیتوریال با لهجهٔ طبیعت (سبز مریم‌گلی + نور گرم)
- ↔️ کاملاً راست‌چین با استفاده از ویژگی‌های منطقی CSS (start/end)
- 🔤 فونت‌های **خودمیزبان**: وزیرمتن (متن) و مرکزی (سربرگ‌ها) — بدون نیاز به CDN خارجی
- 🔢 اعداد فارسی در آمار و متن (۲۰+ ، ۴٬۸۰۰+ ، ۴٫۹)
- 💡 «پنجرهٔ نورِ تعاملی» در هیرو — جابه‌جایی نور با ماوس
- ⚡ خروجی تک‌فایلی (JS/CSS داخل `index.html`) + تصاویر و فونت‌های محلی
- 🔍 سئو: متاتگ‌های فارسی، Open Graph با `fa_IR` و دادهٔ ساخت‌یافتهٔ JSON-LD
- 📱 کاملاً واکنش‌گرا (موبایل / تبلت / دسکتاپ)

## 🚀 اجرای محلی

```bash
npm install
npm run dev        # توسعه
npm run build      # ساخت نسخهٔ نهایی در پوشهٔ dist
npm run preview    # پیش‌نمایش خروجی ساخته‌شده
```

## 🌐 انتشار در GitHub Pages

سایت هم‌اکنون از شاخهٔ **`gh-pages`** منتشر می‌شود (خروجی آماده و ساخته‌شده در آن شاخه قرار دارد).

### انتشار تغییرات جدید

1. تغییرات را روی `main` اعمال و push کنید.
2. محلی بیلد بگیرید و خروجی را روی gh-pages کپی کنید:
   ```bash
   npm run build
   git checkout gh-pages
   cp -r dist/* .
   git add . && git commit -m "به‌روزرسانی سایت" && git push
   ```

### جایگزین: انتشار خودکار با GitHub Actions (اختیاری)

اگر می‌خواهید هر push روی `main` خودکار بیلد و منتشر شود، می‌توانید گردش‌کار
Actions بسازید (بیلد با Node و انتشار `dist/` روی Pages). فایل‌های workflow
با PAT عادی قابل push نیستند — زمانی که خواستید، بگویید تا راه‌اندازی‌اش کنیم.

> مسیرها نسبی (`base: "./"`) تنظیم شده‌اند تا سایت در هر زیرمسیری از
> GitHub Pages بدون خطای ۴۰۴ کار کند.

## 🗂 ساختار پروژه

```
├── index.html              # صفحهٔ اصلی (fa / rtl / سئو)
├── src/
│   ├── App.tsx             # همهٔ بخش‌های صفحه (فارسی و RTL)
│   ├── index.css           # تم Tailwind 4 + فونت‌ها
│   └── main.tsx
├── public/
│   ├── images/             # تصاویر سایت
│   └── fonts/              # فونت‌های خودمیزبان وزیرمتن و مرکزی
├── .github/workflows/      # انتشار خودکار در Pages
└── vite.config.ts          # base نسبی + خروجی تک‌فایلی
```

## 🎨 شخصی‌سازی

- **متن‌ها** در ابتدای `src/App.tsx` (ثابت‌های `NAV`، `SOLUTIONS`، `WHY`، …) قرار دارند.
- **رنگ‌ها** در `src/index.css` داخل بلوک `@theme` تعریف شده‌اند.
- **اطلاعات تماس** در کامپوننت `Footer` (داخل `src/App.tsx`) است.
